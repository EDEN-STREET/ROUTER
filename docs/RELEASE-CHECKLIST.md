# EDEN ROUTER · Release-/Qualitäts-Checkliste

- [ ] Repository tatsächlich öffentlich oder freigegeben angelegt
- [ ] Ursprüngliche Quellen sowie Rechte/Versionen inventarisiert
- [ ] Geräte-/OS- und Firmware-Kompatibilität geprüft
- [ ] Keine privaten Kennungen, Secrets oder nicht lizenzierte Originale im Repo
- [ ] Modelle, Berechtigungen und aktuelle Schnittstellen dokumentiert
- [ ] Read-only Hardware-/Konfigurationsprüfung mit echten Nachweisen
- [ ] Negative Tests einschließlich Abbruch/Recovery
- [ ] Backup und Restore unabhängig verifiziert
- [ ] Keine automatische destruktive Geräteaktion
- [ ] Visuelle HTML-Demo mit klarer Simulationsmarkierung
- [ ] Accessibility, Link- und Browserprüfung bestanden
- [ ] Versionierung, Changelog, Tests, Review und Rollback
- [ ] Explizite Freigabe vor einem produktiven Release
